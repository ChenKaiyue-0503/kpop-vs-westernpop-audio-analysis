# K‑pop与欧美流行音乐音频特征差异及趋同性分析
数据集来源：Kaggle spotify‑tracks‑dataset
工具：Python、Pandas、Matplotlib、Seaborn

## 项目简介
筛选K‑pop与欧美Pop流行歌曲，做样本均衡采样，对比两类音乐音频特征差异，挖掘不同流派歌曲风格规律，面向音乐流媒体输出内容运营参考。

## 分析内容
1. 数据预处理：曲目筛选、样本均衡、缺失值清洗，选取K‑pop(999首)、Pop(1000首)共计1999首歌曲样本
2. 差异分析：舞曲度、能量、情绪、原声占比、说话占比、器乐占比、流行度多维度横向对比
3. 可视化分析：绘制特征对比柱状图、流行度箱线图，直观展示流派风格区别
4. 业务洞察：总结两类音乐风格特征，输出面向音乐内容运营的分析结论

## 主要结论
1. K‑pop舞曲度、能量、积极情绪均值更高，整体偏向动感舞曲风格；Pop原声乐器占比更高。
2. K‑pop流行度分布集中，作品热度整体稳定；普通Pop流行度两极分化，冷热差距明显。

## 项目文件
- `kpop_pop_music_analysis.ipynb`：完整可运行代码，包含全部输出图表
- `kpop_pop_feature_compare.csv`：特征均值统计输出文件
- `images/`：可视化结果截图
