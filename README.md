# K‑pop 与欧美流行音乐音频特征差异及趋同性分析
数据集来源：Kaggle spotify‑tracks‑dataset
工具：Python、Pandas、Matplotlib、Seaborn

## 项目简介
筛选K‑pop与欧美流行歌曲，做样本均衡处理，对比两类音乐音频特征差异，挖掘热门歌曲的共性规律，面向音乐流媒体输出内容运营参考建议。

## 分析内容
1. 数据预处理：筛选曲目、均衡采样、缺失与异常清洗，限定2010‑2025发行歌曲
2. 差异性分析：舞曲度、能量、情绪、BPM、时长、流行度多维度横向对比
3. 趋同性挖掘：提取高热度歌曲，寻找跨类别爆款音乐共同音频特征
4. 时间趋势：2010‑2025两类音乐风格演变
5. 业务洞察：输出歌单策划、海外内容引进的运营优化建议
